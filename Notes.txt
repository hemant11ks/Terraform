Core Concepts:

1. Terraform Core : CLI tool that provisions and manages the infrastructure resource as defined in Terraform config file.
2. Providers : Extends the functionality Terraform for specific plateform such as AWS, OCI and Azure.
3. Resource : Infrastructure components or services that are managed by Terraform such as VM, Network and DNS Record.
4. State : How terraform maps the desired config with real word resoruce on the target plateform.
5. Modules : Resusable and shared blocks of code that can be called and over again.

Terraform State : is a file that tracks resources including their ID and relationships
Without state file, Terraform would not know its current state.

Importance -> Resource Management, Dependency Management and Code Collaboration

TERRAFORM configuration  <--- State File --->  CLOUD Infrastructure

State Storage - JSON Formate (terraform.tfstate)
Terraform lock the state file while performing any operation

Terraform Remote State : Remote state in Terraform means storing your infrastructure's state file
in a shared, off-site data store instead of your local computer.
Common places to store it include Amazon S3, Google Cloud Storage, or HCP Terraform.
